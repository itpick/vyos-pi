VyOS for Raspberry Pi

Flash-and-boot VyOS rolling (arm64) images, built from VyOS's public sources with a Raspberry Pi kernel.

Unofficial community build, not affiliated with or supported by VyOS Networks. The Pi 5 image has booted on one real board (16 GB, from NVMe); the Pi 4 image has only run in QEMU. Fine for labs; keep a working router nearby.

Related projects
  • opnsense-pi: OPNsense images for Raspberry Pi 4/5
  • sensr: Rust + NixOS firewall OS, an OPNsense remake (in development)
  • OPNsense vs VyOS on the Pi 5: side-by-side speed and boot-time results (startup table)

Coming from the OPNsense GUI? The VyOS cheat sheet gives the CLI for DHCP, DNS, firewall, NAT, WireGuard and monitoring.

Boots in QEMU · untested on a board

Raspberry Pi 4

  • Boot: Pi EEPROM → UEFI (pftf/RPi4 v1.54-rc, RAM limit off) → GRUB → VyOS
  • Onboard Ethernet: bcmgenet (ACPI), built in the kernel
  • USB 3 NICs: RTL8153/RTL8156 (r8152), AX88179
  • No AES hardware, so VPNs are CPU-bound

Boots on a real Pi 5

Raspberry Pi 5

  • Verified on a 16 GB board: onboard RP1 Ethernet at 1 Gb/s, USB RTL8156B 2.5 GbE (r8152), NVMe boot, root partition grows on first boot
  • Boot: Pi EEPROM → VyOS kernel + initrd directly, mainline device tree (no UEFI)
  • Onboard Ethernet: RP1 (macb + mainline RP1 driver)
  • add system image upgrades: boot files follow on the FAT partition
  • AES hardware on Cortex-A76; fan not driven by the kernel yet
  • Console on the debug UART; HDMI shows only the firmware's screens
  • 2 GB and 16 GB (D0) boards need a release after 2026.11.16-1

Throughput ceiling on the Pi 5

Theoretical; not yet measured with 5 GbE dongles.

LinkCeiling
Onboard Ethernet1 Gbit/s
Each blue USB 3.0 port5 Gbit/s signalling (USB 3.x Gen 1, 8b/10b coding), so at most 4 Gbit/s of data. A 5 GbE RTL8157 dongle can link at 5 Gbit/s, but on a PC's Gen 1 port it moved 3.47 Gbit/s in iperf3 (4.70 on Gen 2). Expect about 3.5 Gbit/s per port. Each port has its own USB controller in the RP1 chip.
RP1 ↔ SoCPCIe 2.0 x4, about 16 Gbit/s each way, shared by both USB ports and the onboard Ethernet. It is not the limit with two dongles.
Drivervyos-pi's kernel is 6.18, and its r8152 driver does not know the RTL8157 (USB ID 0bda:8157; modinfo r8152 on a vyos-pi router has no 8157 alias). Mainline gained it in Linux 7.1. So today the fastest USB NIC that works is a 2.5 GbE RTL8156/RTL8156B, about 2.35 Gbit/s per port.
Through the routerThe lowest of the WAN port, the LAN port and what the CPU can forward. The firewall rules, NAT and Suricata set the real figure. Measured so far.

Try it on a Pi 5 that already runs another OS (recommended)

pi-trial-install.sh writes vyos-pi to an NVMe or USB disk and boots it once through the firmware's tryboot, keeping Raspberry Pi OS or Ubuntu as the default. If VyOS fails in any way, the Pi comes back to the old OS by itself, with boot logs on its boot partition. Happy with VyOS: --commit makes it the default. How it works.

curl -fLO https://raw.githubusercontent.com/itpick/vyos-pi/main/scripts/pi-trial-install.sh && chmod +x pi-trial-install.sh
sudo ./pi-trial-install.sh https://github.com/itpick/vyos-pi/releases/latest/download/vyos-pi-pi5.img.xz /dev/nvme0n1
sudo ./pi-trial-install.sh --reboot

One-liner (Linux): a fresh card or disk

Writes the Pi 5 image straight to a disk. Replace /dev/sdX; everything on it is erased.

curl -fL https://github.com/itpick/vyos-pi/releases/latest/download/vyos-pi-pi5.img.xz | xz -dc | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

Or, in Raspberry Pi Imager, choose Use custom and select the downloaded .img.xz.

First boot

  1. Update the EEPROM bootloader first (Raspberry Pi OS: sudo rpi-eeprom-update -a).
  2. Optional, before the first boot: make a config.boot with seed-config.py (hostname, SSH key, LAN/WAN by MAC, DHCP, DNS, NAT, firewall) and copy it to vyos-pi/config.boot on the card's FAT partition.
  3. Boot. The root partition grows to fill the card. Log in on the serial console (Pi 4: or HDMI) as vyos / vyos and change the password, or SSH in with the seeded key.
  4. Without a seed, configure from the CLI: configure, then set interfaces ethernet eth0 address dhcp and so on (VyOS quick start).

Build it yourself

Needs Docker on an arm64 machine (Linux or an Apple Silicon Mac).

git clone https://github.com/itpick/vyos-pi && cd vyos-pi && make iso && make images
